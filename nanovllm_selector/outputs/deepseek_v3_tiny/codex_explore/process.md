# Codex 独立移植记录

本次使用本地 checkpoint `tmp/models/deepseek-v3-tiny-katuni4ka`、镜像 `nanovllm-explore-worker:local` 和物理 GPU2。本目录的 `prompt.json` 和 `tool.jsonl` 保留完整本地会话。仓库中的证据摘要记录查询的符号、源码位置与摘要、各步观测和完整张量的对照结果。探针可独立查看。[证据摘要](evidence.json) · [探针](probe.py)

1. 用 `read_code` 查到第一层是稠密 MLP，第二层含路由专家与共享专家。注意力把低秩投影还原为每头 4 列的 Q/K 和 2 列的 V。短前向确认原生运行使用 FP32、ROCm SDPA。
2. `run_model` 以 `[101, 113, 7, 23]` 预填充，再依次输入 `31`、`19`。三个步骤均通过原生运行校准。独立探针用 PyTorch 重算第一层 RMSNorm、含旋转和历史 K/V 的注意力，以及第二层的分组路由、专家加权累加和共享专家输出。`observe` 读到首个词元选择的六个专家为 `[27, 118, 110, 55, 29, 107]`。九次 `compare` 均为 `match`，覆盖形状 `[1,4,8]` 和 `[1,1,8]` 的完整张量。完整观测张量保存在本地 `runs/`，可按证据摘要中的运行编号查询。
3. 将上述计算写成 [attempt_1.py](attempt_1.py)。模型按引擎的 `slot_mapping` 写入等宽 K/V 页，读取时恢复 V 的实际宽度。路由分组依据带校正偏置的分数选择专家，组合权重取自原始 sigmoid 分数，按专家编号升序累加。
