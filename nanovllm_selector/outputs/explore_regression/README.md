# 主动探索接口的单卡回归

引擎 `ba57abd` 在物理 GPU1 验证了 Qwen3-0.6B、Llama-3.2-1B、MiniCPM5-1B、LFM2.5-1.2B-Base 的原有候选。每个模型的常规 12 个位置和独立 10 个位置全部通过，共 10,478,336 个 BF16 词表值，最大绝对差为零。项目既有套件通过 159 项，引擎套件通过 33 项，均无跳过。汇总含每份结果的相对路径、候选与权重摘要、设备和复现命令。[最终汇总](engine_ba57abd/summary.json)

针对主动接口的分项验证还包括真实共享模块的调用序号、可重用的张量地址、实际隔离容器的文件交接、故障时的独立数值诊断，以及中断后复用原候选和报告。对 Jamba、Zamba、Mamba 的 CPU 小模型，参照缓存初始化的回归覆盖了 2,220 个 FP32 分数。它们与原生生成接口逐项相等。这里测的是参照运行，整模型移植结果另见 DeepSeek-V3 tiny。[参照测试](../../port/test_evaluate_reference.py) · [DeepSeek 端到端结果](../deepseek_v3_tiny/README.md)

开发容器的早期试跑触发过三份宿主机进程转储和一份崩溃报告。按授权核对归属后已定向清理，共 3,143,181,650 字节。隔离执行器显式关闭 core 转储。若编译出的共享库需要加载，使用容器私有的 `/jit`。本地的 `apport_cleanup.log` 和 `tmpfs_diagnosis.log` 保留这两处运行环境问题的记录。各模块使用各自已完成的运行记录，自动审批拒绝了一次重复发起的聚合测试。

保留的临时观测样本位于本目录的 `tool_samples/`。需要释放本机空间时可以删除该目录，正式模型报告位于 `engine_ba57abd/`，中间版本的报告位于 `engine_db396bd/`。
